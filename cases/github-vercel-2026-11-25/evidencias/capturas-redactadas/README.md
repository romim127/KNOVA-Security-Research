# E-01 a E-04 — Capturas redactadas

**Pendiente de incorporar originales sanitizados.** Los originales se observaron en la conversación, pero no se publican porque pueden contener parámetros OAuth y datos personales.

Antes de subir: recortar u ocultar URL con `state`, `code`, `iss`, IDs de sesión/cuenta, correos, tokens y cookies. Conservar solo la hora, el código de error y el contexto mínimo. Registrar fecha, acción y procedencia de cada imagen. No fabricar ni reconstruir supuestas capturas reales.
